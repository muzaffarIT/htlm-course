📝 Работа с текстом в HTML

Текст — основа любого сайта. HTML предлагает множество способов оформить и структурировать текст. Главное правило: каждый текст должен находиться внутри какого-либо тега.

📝 Полный пример текстовых тегов
<!DOCTYPE html><html><head><meta charset="UTF-8"></head>
<body>
  <h1>Моя статья о программировании</h1>
  <p>Программирование — это <strong>создание инструкций</strong>
  для компьютера. Это <em>увлекательно</em> и <mark>перспективно</mark>.</p>

  <h2>Зачем учиться программированию?</h2>
  <p>Первая причина: <abbr title="Информационные технологии">IT</abbr>
  — одна из самых высокооплачиваемых сфер!</p>

  <p>Ты можешь создать:<br>
  — Веб-сайты<br>
  — Мобильные приложения<br>
  — Игры</p>

  <hr>
  <p><small>Автор: Музаффар Хаётов, 2025</small></p>
</body></html>

🔤 Специальные символы

Некоторые символы нельзя писать прямо в HTML — например, угловые скобки < и > воспринимаются как теги. Для них используют HTML-сущности:

🔤 HTML-сущности
&lt;   → <   (меньше)
&gt;   → >   (больше)
&amp;  → &   (амперсанд)
&quot; → "   (кавычки)
&nbsp; →     (неразрывный пробел)
&copy; → ©   (авторское право)
&reg;  → ®   (зарегистрированный знак)
&mdash;→ —   (длинное тире)
💡 Использование HTML-сущностей обязательно, когда символ может быть воспринят браузером как часть кода.

📋 Предварительно отформатированный текст

Тег <pre> сохраняет все пробелы и переносы строк как есть. Он часто используется для отображения кода или стихов:

📋 Тег pre
<pre>
  function hello() {
    console.log("Привет!");
  }
</pre>
