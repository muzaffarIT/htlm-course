📋 Маркированный список <ul>

ul (unordered list — неупорядоченный список) создаёт список с маркерами (точки, кружки, квадраты). Каждый пункт — тег <li> (list item).

📋 Маркированные списки
<ul>
  <li>HTML — структура</li>
  <li>CSS — оформление</li>
  <li>JavaScript — логика</li>
</ul>

<!-- Вложенный список -->
<ul>
  <li>Фронтенд
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
  </li>
  <li>Бэкенд
    <ul>
      <li>Python</li>
      <li>Node.js</li>
    </ul>
  </li>
</ul>

🔢 Нумерованный список <ol>

ol (ordered list — упорядоченный список) создаёт нумерованный список. Можно настроить начало нумерации и тип:

🔢 Нумерованные списки
<!-- Обычный список 1, 2, 3... -->
<ol>
  <li>Первый шаг</li>
  <li>Второй шаг</li>
  <li>Третий шаг</li>
</ol>

<!-- Буквы: a, b, c -->
<ol type="a">
  <li>Вариант А</li>
  <li>Вариант Б</li>
</ol>

<!-- Начать с 5 -->
<ol start="5">
  <li>Пятый пункт</li>
  <li>Шестой пункт</li>
</ol>

📊 Таблицы

Таблицы используются для отображения данных в строках и столбцах. Основные теги:

  • <table> — контейнер таблицы
  • <thead> — шапка таблицы
  • <tbody> — тело таблицы
  • <tr> — строка (table row)
  • <th> — заголовочная ячейка (жирная, по центру)
  • <td> — обычная ячейка (table data)
📊 Полная таблица
<table border="1" cellpadding="8" style="border-collapse: collapse;">
  <thead>
    <tr>
      <th>Язык</th>
      <th>Назначение</th>
      <th>Сложность</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML</td>
      <td>Структура</td>
      <td>⭐ Лёгкий</td>
    </tr>
    <tr>
      <td>CSS</td>
      <td>Оформление</td>
      <td>⭐⭐ Средний</td>
    </tr>
    <tr>
      <td>JavaScript</td>
      <td>Логика</td>
      <td>⭐⭐⭐ Сложный</td>
    </tr>
  </tbody>
</table>
💡 Атрибуты colspan и rowspan позволяют объединять ячейки по горизонтали и вертикали.
