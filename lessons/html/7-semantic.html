🧩 Что такое семантика?

Семантика — это смысл. Семантические теги помогают браузеру, поисковикам и программам для людей с ограниченными возможностями понять что значит каждая часть страницы, а не просто как она выглядит.

💡 Раньше все писали: <div id="header">, <div id="nav">... HTML5 добавил теги с понятными именами!
🧩 Несемантический vs Семантический
<!-- ❌ Несемантический (старый способ) -->
<div id="header">...</div>
<div id="nav">...</div>
<div id="main">...</div>
<div id="footer">...</div>

<!-- ✅ Семантический (правильный HTML5) -->
<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>

🏗️ Основные семантические теги

🏗️ Структура страницы
<header>   — шапка сайта (логотип, навигация)
<nav>      — блок навигации (меню)
<main>     — основное содержимое страницы
<section>  — раздел страницы
<article>  — самостоятельная статья/запись
<aside>    — боковая панель
<footer>   — подвал сайта
<figure>   — иллюстрация с подписью
<figcaption> — подпись к иллюстрации
<time>     — дата/время
<address>  — контактная информация

📐 Полная структура страницы

📐 Полный шаблон HTML5
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Описание сайта для поисковиков">
  <title>WebAcademy — Обучение</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <header>
    <a href="/" class="logo">🚀 WebAcademy</a>
    <nav>
      <a href="/courses">Курсы</a>
      <a href="/about">О нас</a>
      <a href="/contact">Контакты</a>
    </nav>
  </header>

  <main>
    <section id="hero">
      <h1>Учись веб-разработке</h1>
      <p>Уроки от Музаффара Хаётова</p>
    </section>

    <section id="articles">
      <article>
        <h2>Урок 1: HTML</h2>
        <time datetime="2025-01-01">1 января 2025</time>
        <p>Изучаем основы HTML...</p>
        <figure>
          <img src="html.png" alt="HTML код">
          <figcaption>Пример HTML-кода</figcaption>
        </figure>
      </article>
    </section>

    <aside>
      <h3>Полезные ссылки</h3>
      <ul>
        <li><a href="#">MDN Web Docs</a></li>
      </ul>
    </aside>
  </main>

  <footer>
    <address>
      Автор: <a href="mailto:muzaffar@webacademy.uz">Музаффар Хаётов</a>
    </address>
    <p>&copy; 2025 WebAcademy</p>
  </footer>

</body>
</html>
✅ Правильный семантический HTML улучшает SEO (поисковое продвижение), доступность и читаемость кода!

📝 Финальное задание HTML

Создай полноценную страницу личного блога с правильной семантикой:

  • 1Создай структуру: header с логотипом и nav, main, footer
  • 2Внутри main добавь section с 2–3 article (твои посты)
  • 3Добавь aside с виджетом «Обо мне» или «Категории»
  • 4Каждый article должен содержать h2, time, p и figure с img
  • 5В footer добавь address с твоим именем и email
