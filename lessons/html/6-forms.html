📋 Что такое HTML-форма?

Формы — это способ получить данные от пользователя. Когда ты вводишь логин и пароль на сайте, заполняешь анкету или делаешь заказ — ты используешь HTML-форму!

Основной тег — <form>. Внутри него — различные поля ввода.

📋 Базовая форма
<form action="/submit" method="POST">
  <!-- поля формы -->
</form>

Атрибуты тега form:

  • action — URL, куда отправляются данные
  • method — способ отправки: GET (данные в URL) или POST (данные скрыты)

⌨️ Поля ввода <input>

Тег <input> — главный элемент формы. Тип поля задаётся атрибутом type:

⌨️ Типы полей input
<!-- Текстовое поле -->
<input type="text" placeholder="Введи имя">

<!-- Email -->
<input type="email" placeholder="email@mail.com">

<!-- Пароль -->
<input type="password" placeholder="Пароль">

<!-- Число -->
<input type="number" min="0" max="100">

<!-- Дата -->
<input type="date">

<!-- Чекбокс -->
<input type="checkbox"> Я согласен с условиями

<!-- Радио-кнопка -->
<input type="radio" name="gender" value="male"> Мальчик
<input type="radio" name="gender" value="female"> Девочка

<!-- Файл -->
<input type="file">

<!-- Скрытое поле -->
<input type="hidden" value="secret_value">

<!-- Кнопка отправки -->
<input type="submit" value="Отправить">

📝 Другие элементы форм

📝 textarea, select, button
<!-- Многострочное поле -->
<textarea rows="5" cols="40" placeholder="Напиши сообщение..."></textarea>

<!-- Выпадающий список -->
<select>
  <option value="">-- Выбери --</option>
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="js">JavaScript</option>
</select>

<!-- Метка (label) привязывает текст к полю -->
<label for="name">Твоё имя:</label>
<input type="text" id="name" name="name">

<!-- Кнопка -->
<button type="submit">🚀 Отправить</button>
<button type="reset">🔄 Сбросить</button>
✅ Атрибут required делает поле обязательным. Атрибут disabled делает поле неактивным.
