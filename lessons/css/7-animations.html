Магия @keyframes

В CSS можно делать настоящие мультики! Для этого используется правило @keyframes. В нем мы прописываем кадры нашей анимации: что происходит на 0% (начало), 50% (середина) и 100% (конец).

Чтобы запустить анимацию, элементу нужно добавить свойство animation: название время infinite;. infinite означает, что анимация будет повторяться бесконечно!

@keyframes bounce {
    0% { transform: translateY(0); } /* Внизу */
    50% { transform: translateY(-40px); } /* Подпрыгнул вверх на 40px */
    100% { transform: translateY(0); } /* Вернулся вниз */
}

.ball {
    animation: bounce 2s infinite;
}

🔥 Мини-задание: Вращение

Чтобы крутить элементы, мы используем внутри анимации команду transform: rotate(...). Напиши анимацию @keyframes spin, которая начинает с 0deg (градусов) на 0% и заканчивает на 360deg в 100%.

@keyframes spin {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}
