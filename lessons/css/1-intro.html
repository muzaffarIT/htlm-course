Часть 1: Что такое CSS? 🎨

Учимся красить и стилизовать наш скучный HTML-код.

Как макияж для сайта

HTML — это как кирпичи и стены дома. А CSS (Cascading Style Sheets) — это краска, обои и красивая мебель.

Чтобы добавить стиль, мы пишем имя элемента (например, h1), затем открываем фигурные скобки {} и внутри пишем правила. Правило состоит из названия свойства и значения.

/* Это комментарий в CSS. Он ничего не делает на странице, просто подсказка! */
h1 {
    color: blue; /* Свойство color меняет цвет текста */
}

Как мы это сделали?

В примере "ПОСЛЕ" мы использовали CSS-правило: color: #3A86FF; (это красивый оттенок синего). Тег <h1> окрасился в этот цвет, стал больше и расположился по центру!

🔥 Мини-задание: Напиши свое первое правило

Представь, что у тебя есть тег абзаца <p>. Напиши ниже код CSS, который сделает текст красным (red). Можешь просто написать это на бумажке или в голове, а потом проверить себя.

p {
    color: red;
}
