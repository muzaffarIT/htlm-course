🎨 Что такое CSS?

CSS (Cascading Style Sheets — Каскадные таблицы стилей) — это язык, который описывает как выглядит HTML-страница. HTML создаёт структуру, CSS — делает её красивой!

Без CSS все сайты выглядели бы как скучные текстовые документы — чёрный текст на белом фоне. CSS отвечает за цвета, шрифты, размеры, расположение элементов, анимации и многое другое.

💡 CSS расшифровывается как Cascading (каскадный) — потому что стили «каскадируются» (наследуются) от родительских элементов к дочерним.

📋 Три способа добавить CSS

📋 Способы подключения CSS
<!-- 1. Внешний файл (ЛУЧШИЙ способ!) -->
<head>
  <link rel="stylesheet" href="style.css">
</head>

<!-- 2. Внутри тега style в head -->
<head>
  <style>
    h1 { color: purple; }
  </style>
</head>

<!-- 3. Инлайн (прямо в теге — нежелательно) -->
<h1 style="color: purple; font-size: 32px;">Заголовок</h1>

🎯 Синтаксис CSS — Селекторы и свойства

CSS правило состоит из селектора и блока объявлений:

🎯 Синтаксис CSS
селектор {
  свойство: значение;
  свойство: значение;
}

/* Примеры селекторов: */

/* По тегу */
h1 { color: purple; }
p  { font-size: 16px; }

/* По классу (class="btn") */
.btn { background: blue; color: white; }

/* По id (id="header") */
#header { background: black; }

/* По атрибуту */
input[type="email"] { border: 2px solid blue; }

/* Несколько селекторов */
h1, h2, h3 { font-family: Arial; }

/* Вложенный элемент */
nav a { color: white; text-decoration: none; }

/* Все элементы */
* { box-sizing: border-box; }

⚡ Основные CSS-свойства

⚡ Базовые свойства
/* Текст */
color: red;              /* цвет текста */
font-size: 18px;         /* размер шрифта */
font-weight: bold;       /* жирность */
text-align: center;      /* выравнивание */
text-decoration: none;   /* подчёркивание */

/* Фон */
background-color: #f5f5f5;
background-image: url('bg.jpg');

/* Размеры */
width: 300px;
height: 200px;
max-width: 100%;

/* Отступы */
margin: 20px;            /* внешний отступ */
padding: 10px;           /* внутренний отступ */

/* Рамка */
border: 2px solid #ccc;
border-radius: 10px;     /* скруглённые углы */
