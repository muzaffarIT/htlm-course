Часть 5: Flexbox — Расставляем по местам 🧱

Учимся строить элементы в ряд и делать модные сетки.

Блоки или Строки?

По умолчанию все блоки на сайте (например, <div>) выстраиваются один под другим. Но что, если мы хотим поставить их в один ряд, как меню сверху сайта?

Для этого мы делаем их родительский контейнер гибким: display: flex;. Теперь все элементы внутри начинают строиться в цепочку как вагончики!

.container {
    display: flex; /* Включаем магию Flexbox */
    justify-content: space-around; /* Делаем между ними одинаковые отступы */
}

Сила Flexbox

Благодаря justify-content: space-around; блоки не просто выстроились в ряд, но и равномерно распределили свободное пространство между собой. Flexbox — это самый популярный инструмент в современном веб-дизайне!

🔥 Мини-задание: Выравниваем по центру

Свойство justify-content отвечает за то, где стоят наши блоки по горизонтали. Какое значение (вместо space-around) нужно использовать, чтобы скомкать все блоки четко по центру?

.container {
    display: flex;
    justify-content: center; /* Центрирует элементы */
}
