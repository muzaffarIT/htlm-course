📐 Что такое Flexbox?

Flexbox (Flexible Box) — это мощный инструмент CSS для создания гибких, отзывчивых макетов. До Flexbox расположение элементов было очень сложным. Сейчас — это всего несколько строк!

Flexbox работает с родительским контейнером (flex container) и его дочерними элементами (flex items).

📐 Основы Flexbox
/* Включаем Flexbox у родителя */
.container {
  display: flex;

  /* Направление */
  flex-direction: row;            /* по горизонтали (умолчание) */
  flex-direction: column;         /* по вертикали */
  flex-direction: row-reverse;    /* горизонталь наоборот */

  /* Выравнивание по главной оси (горизонталь при row) */
  justify-content: flex-start;    /* слева */
  justify-content: flex-end;      /* справа */
  justify-content: center;        /* по центру */
  justify-content: space-between; /* с пробелами между */
  justify-content: space-around;  /* с пробелами вокруг */
  justify-content: space-evenly;  /* равные пробелы */

  /* Выравнивание по поперечной оси (вертикаль при row) */
  align-items: flex-start;   /* наверх */
  align-items: flex-end;     /* вниз */
  align-items: center;       /* по центру */
  align-items: stretch;      /* растянуть (умолчание) */

  /* Перенос элементов */
  flex-wrap: nowrap;   /* без переноса (умолчание) */
  flex-wrap: wrap;     /* перенос на новую строку */

  /* Отступы между элементами */
  gap: 20px;
  column-gap: 20px;
  row-gap: 10px;
}

🎯 Свойства flex-элементов

🎯 Flex Items
/* Гибкость элемента */
.item {
  flex-grow: 1;    /* занять свободное место (число = доля) */
  flex-shrink: 0;  /* не сжиматься */
  flex-basis: 200px; /* начальный размер */

  /* Сокращённая запись */
  flex: 1;           /* flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
  flex: 0 0 200px;   /* фиксированный 200px */

  /* Порядок элемента */
  order: 2;  /* изменить порядок без изменения HTML */

  /* Индивидуальное выравнивание */
  align-self: center;    /* переопределяет align-items для этого элемента */
}
✅ Совет: Самый частый паттерн — display: flex; align-items: center; justify-content: center; — центрирует содержимое идеально!
