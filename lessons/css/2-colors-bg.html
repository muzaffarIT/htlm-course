🌈 Форматы цветов в CSS

CSS поддерживает несколько способов записи цвета. Каждый из них имеет свои преимущества:

🌈 Форматы цветов
/* 1. Именованные цвета */
color: red;
color: purple;
color: tomato;
color: dodgerblue;

/* 2. HEX (шестнадцатеричный) */
color: #FF0000;     /* красный */
color: #7C3AED;     /* фиолетовый */
color: #fff;        /* белый (краткая запись) */

/* 3. RGB */
color: rgb(255, 0, 0);        /* красный */
color: rgb(124, 58, 237);     /* фиолетовый */

/* 4. RGBA (A = прозрачность 0.0–1.0) */
color: rgba(124, 58, 237, 0.5);  /* полупрозрачный */

/* 5. HSL (тон, насыщенность, светлота) */
color: hsl(270, 70%, 58%);

/* 6. Прозрачный */
color: transparent;
💡 HEX-цвета — самый популярный формат у веб-дизайнеров. Используй сервис colorhunt.co для красивых палитр!

🖼️ Свойства фона

🖼️ Background свойства
/* Цвет фона */
background-color: #f5f5f5;

/* Фоновое изображение */
background-image: url('background.jpg');

/* Размер фона */
background-size: cover;    /* растянуть на всю область */
background-size: contain;  /* вписать полностью */
background-size: 300px;    /* конкретный размер */

/* Позиция фона */
background-position: center;
background-position: top left;
background-position: 50% 30%;

/* Повторение */
background-repeat: no-repeat;  /* без повторений */
background-repeat: repeat-x;   /* только по горизонтали */

/* Короткая запись (всё в одной строке) */
background: url('bg.jpg') center/cover no-repeat;

/* Градиент */
background: linear-gradient(135deg, #667eea, #764ba2);
background: radial-gradient(circle, #f59e0b, #d97706);

✨ Красивые градиенты

✨ Примеры градиентов
/* Линейные градиенты */
background: linear-gradient(to right, #f59e0b, #ef4444);
background: linear-gradient(135deg, #7C3AED, #EC4899);
background: linear-gradient(to bottom, #0f0f1a, #1a1a38);

/* С несколькими цветами */
background: linear-gradient(135deg, #f093fb, #f5576c, #fda085);

/* Радиальный градиент */
background: radial-gradient(circle at center, #7C3AED 0%, #0D0D1A 70%);

/* Использование для текста! */
.gradient-text {
  background: linear-gradient(135deg, #A78BFA, #F59E0B);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}

🌗 Прозрачность и opacity

🌗 Прозрачность
/* opacity — прозрачность всего элемента (0.0–1.0) */
.overlay { opacity: 0.5; }

/* rgba — прозрачность только фона */
.glass { background: rgba(255, 255, 255, 0.1); }

/* Glassmorphism эффект */
.glass-card {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 16px;
}
