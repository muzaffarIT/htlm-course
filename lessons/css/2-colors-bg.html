Часть 2: Цвета и Фон 🌈

Добавляем яркие краски с помощью CSS.

color и background-color

В CSS есть два главных свойства для цветов:

  • color — меняет цвет самого текста.
  • background-color — меняет цвет фона позади текста/блока.

Цвета можно писать обычными словами (red, blue) или специальными кодами (Хекс-кодами, например #8338EC).

div {
    background-color: #8338EC; /* Фиолетовый фон */
    color: white; /* Белый текст */
}

Почему это круто?

Без background-color блоки сливаются с общим фоном страницы. С фоном мы можем выделять важные вещи, как кнопки или предупреждения.

🔥 Мини-задание: Ночная тема

Как бы ты написал CSS для тега <body>, чтобы сделать "ночную тему" (черный фон страницы и белый цвет текста)?

body {
    background-color: black;
    color: white;
}
