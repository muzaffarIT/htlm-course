📍 CSS Position

Свойство position управляет тем, как элемент размещается на странице. Значения: static, relative, absolute, fixed, sticky.

📍 Типы позиционирования
/* static — по умолчанию, обычный поток документа */
.element { position: static; }

/* relative — смещение от обычного положения */
.element {
  position: relative;
  top: 20px;    /* сдвинуть вниз на 20px */
  left: 10px;   /* сдвинуть вправо на 10px */
}

/* absolute — позиция относительно ближайшего
   positioned родителя (не static) */
.parent { position: relative; }
.child {
  position: absolute;
  top: 0;
  right: 0;     /* прижать к верхнему правому углу родителя */
}

/* fixed — зафиксирован относительно экрана */
.navbar {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 100; /* поверх других элементов */
}

/* sticky — обычный, пока не достигнет порога */
.header {
  position: sticky;
  top: 0;       /* "прилипает" при прокрутке к верху */
}

/* z-index — порядок наложения (чем больше, тем выше) */
.overlay { z-index: 50; }
.modal   { z-index: 100; }

✨ Hover-эффекты и псевдоклассы

✨ Псевдоклассы и эффекты
/* :hover — когда курсор над элементом */
.btn:hover {
  background: #5B21B6;
  transform: translateY(-3px);
  box-shadow: 0 8px 25px rgba(124,58,237,0.4);
}

/* :active — когда кнопка нажата */
.btn:active { transform: scale(0.97); }

/* :focus — когда элемент в фокусе */
input:focus { border-color: #7C3AED; outline: none; }

/* :first-child, :last-child */
li:first-child { color: gold; }
li:last-child  { color: red; }

/* :nth-child() — выбрать конкретный */
tr:nth-child(even) { background: #f5f5f5; }
tr:nth-child(3)    { font-weight: bold; }

/* ::before и ::after — псевдоэлементы */
.card::before {
  content: '';
  position: absolute;
  top: 0; left: 0; right: 0;
  height: 4px;
  background: linear-gradient(90deg, #7C3AED, #EC4899);
}

/* Transitions — плавные переходы */
.btn {
  transition: all 0.3s ease;
  /* или */
  transition: background 0.2s, transform 0.3s ease;
}
💡 transform — мощное свойство для анимации: translateX(), translateY(), scale(), rotate() — не влияет на layout!
