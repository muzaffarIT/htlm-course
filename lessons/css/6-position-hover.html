Часть 6: Вау-Эффекты при наведении ✨

Делаем сайт живым: как реагировать на мышку.

Псевдокласс :hover

В CSS есть способ узнать, когда курсор мыши находится поверх элемента (например, кнопки). Для этого к названию элемента в CSS приписывают :hover (наведение).

Еще есть классное свойство transition. Если мы просто поменяем цвет, он изменится резко. transition делает так, что цвет перетекает плавно, как в кино!

button {
    background-color: green;
    transition: 0.3s; /* Плавность эффекта занимает 0.3 секунды */
}

button:hover {
    background-color: pink; /* При наведении меняем на розовый */
    transform: scale(1.1); /* Немного увеличиваем размер */
}

Почему это важно?

Hover-эффекты подсказывают пользователю: "Сюда можно нажать!". Это делает сайт приятным и понятным.

🔥 Мини-задание: Подсвечиваем ссылки

Как сделать так, чтобы при наведении мыши на любую ссылку (<a>) на сайте, её текст становился оранжевым (orange)?

a:hover {
    color: orange;
}
