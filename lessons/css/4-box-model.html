Часть 4: Коробки и Отступы 📦

Узнаем про магию Margin, Padding и Border (Box Model).

Все элементы — это коробки

Чтобы элементы на сайте не слипались друг с другом, у нас есть три волшебных свойства:

  • padding (внутренний отступ) — пространство внутри коробки, между текстом и стенками.
  • border (рамка/граница) — стенки самой коробки.
  • margin (внешний отступ) — пространство снаружи коробки, до соседних элементов.
div {
    padding: 20px; /* Текст не липнет к краю */
    border: 5px solid red; /* Толстая красная сплошная рамка */
    margin: 20px; /* Отталкивает соседние элементы на 20px */
}

Что тут произошло?

Серый фон с пунктиром — это контейнер. В левом примере синий блок прилип к его краям, а текст внутри блока — к его стенкам. В правом примере блок "дышит": у него появились внутренние отступы (padding), красивые края (border) и внешние отступы (margin), которые отодвинули его от краев контейнера.

🔥 Мини-задание: Создаем рамку

Напиши CSS для создания черной рамки толщиной 2 пикселя вокруг картинки (<img>). Стиль линии сделай сплошным (solid).

img {
    border: 2px solid black;
}
