📦 Что такое Box Model?

Каждый HTML-элемент в CSS представлен как прямоугольная коробка (box). Эта модель состоит из четырёх уровней (снаружи внутрь):

  1. Margin (внешний отступ) — пространство вокруг элемента
  2. Border (рамка) — граница элемента
  3. Padding (внутренний отступ) — пространство внутри рамки
  4. Content (содержимое) — сам текст или изображение
📦 Box Model пример
.box {
  /* Содержимое */
  width: 200px;
  height: 100px;

  /* Внутренний отступ */
  padding: 20px;           /* со всех сторон */
  padding: 10px 20px;      /* верх-низ | лево-право */
  padding: 10px 15px 20px 25px; /* верх | право | низ | лево */
  padding-top: 10px;       /* только сверху */

  /* Рамка */
  border: 2px solid #7C3AED;
  border-width: 2px;
  border-style: solid;     /* solid | dashed | dotted | none */
  border-color: purple;
  border-radius: 12px;     /* скруглённые углы */

  /* Внешний отступ */
  margin: 20px;
  margin: 0 auto;          /* центровка по горизонтали */
  margin-top: 30px;
}
💡 Важно! По умолчанию width и height — это размер только содержимого. Padding и border добавляются поверх. Чтобы это исправить, используй: box-sizing: border-box

🔧 box-sizing: border-box

🔧 box-sizing
/* Лучшая практика — всегда добавляй в начало CSS */
* {
  box-sizing: border-box;
}

/* Теперь width включает padding и border!
   Без border-box: width=200px + padding=40px = 240px итого
   С border-box:   width=200px (уже включает padding) */

.card {
  width: 300px;     /* это ИТОГОВАЯ ширина */
  padding: 20px;    /* уже включена в 300px */
  border: 2px solid #ccc;  /* тоже включена */
}

🌟 Тени и визуальные эффекты

🌟 Box Shadow
/* box-shadow: x y blur spread color */
box-shadow: 2px 2px 4px rgba(0,0,0,0.2);
box-shadow: 0 4px 20px rgba(0,0,0,0.3);
box-shadow: 0 0 30px rgba(124,58,237,0.4); /* свечение */

/* Несколько теней */
box-shadow: 0 2px 8px rgba(0,0,0,0.2),
            0 0 20px rgba(124,58,237,0.15);

/* Внутренняя тень */
box-shadow: inset 0 2px 4px rgba(0,0,0,0.2);

/* outline — контур вне рамки (не влияет на layout) */
outline: 2px solid #7C3AED;
outline-offset: 3px;
