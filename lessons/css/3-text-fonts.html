🔤 CSS-свойства текста

Типографика — одна из важнейших составляющих дизайна. CSS даёт полный контроль над внешним видом текста:

🔤 Все свойства текста
/* Шрифт */
font-family: 'Arial', sans-serif;
font-size: 18px;           /* размер */
font-weight: bold;         /* жирность: 100-900, bold, normal */
font-style: italic;        /* стиль: normal, italic, oblique */
font-variant: small-caps;  /* все буквы заглавные, но маленькие */

/* Текст */
color: #333;
text-align: center;        /* left | right | center | justify */
text-decoration: underline;/* none | underline | line-through | overline */
text-transform: uppercase; /* uppercase | lowercase | capitalize */
letter-spacing: 2px;       /* расстояние между буквами */
word-spacing: 5px;         /* расстояние между словами */
line-height: 1.7;          /* межстрочный интервал */
text-shadow: 2px 2px 4px rgba(0,0,0,0.3); /* тень */
text-indent: 30px;         /* отступ первой строки */
white-space: nowrap;       /* не переносить текст */
overflow: hidden;          /* скрыть переполненный текст */
text-overflow: ellipsis;   /* ... для обрезанного текста */

🌐 Google Fonts

Google Fonts — бесплатная библиотека красивых шрифтов. Подключается через тег <link>:

🌐 Подключение Google Fonts
<!-- В head вашей страницы -->
<link href="https://fonts.googleapis.com/css2?family=Nunito:wght@400;700;900&family=Roboto:wght@300;400;500&display=swap" rel="stylesheet">

/* Использование в CSS */
body {
  font-family: 'Nunito', sans-serif;
}

h1 {
  font-family: 'Roboto', sans-serif;
  font-weight: 900;
}

/* Популярные шрифты на Google Fonts:
   - Nunito (дружелюбный)
   - Inter (современный)
   - Roboto (нейтральный)
   - Montserrat (стильный)
   - Poppins (округлый)
   - JetBrains Mono (для кода)
*/

📐 Единицы измерения в CSS

📐 Единицы
/* Абсолютные */
font-size: 18px;   /* пиксели — самые распространённые */
font-size: 14pt;   /* пункты (используется в печати) */

/* Относительные */
font-size: 1.2em;  /* 1.2 × размер родительского элемента */
font-size: 1.2rem; /* 1.2 × базовый размер страницы (16px) */
font-size: 5vw;    /* 5% ширины окна браузера */
font-size: 5vh;    /* 5% высоты окна браузера */

/* Лучшая практика */
html { font-size: 16px; }      /* базовый размер */
body { font-size: 1rem; }      /* 16px */
h1   { font-size: 2.5rem; }   /* 40px */
p    { font-size: 1.1rem; }   /* 17.6px */
