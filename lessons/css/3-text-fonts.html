Часть 3: Текст и Шрифты 🔠

Учимся управлять размером, красивыми шрифтами и выравниванием.

Как менять буквы?

У CSS есть целая группа свойств, начинающихся на font- и text-:

  • font-size — размер шрифта (например, 24px).
  • font-family — название шрифта (например, Arial или красивый Pacifico).
  • font-weight — толщина (bold для жирного).
  • text-align — выравнивание текста по центру (center), слева (left) или справа (right).
p {
    font-family: 'Pacifico', cursive;
    font-size: 28px;
    text-align: center;
    color: #FF006E;
}
