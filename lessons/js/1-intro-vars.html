Часть 1: Привет, JavaScript! 🧠

Делаем сайт умным. Учимся сохранять данные в переменные.

Что такое JavaScript (JS)?

Если HTML — это дом, а CSS — покраска стен, то JavaScript у нас отвечает за проводку и электричество. Именно JS заставляет кнопки нажиматься, всплывать окнам и двигаться объектам от действий пользователя!

В JS мы пишем код внутри тега <script> прямо перед закрывающимся тегом </body> в нашей HTML странице.

Переменные - это коробочки

В программировании нам часто нужно что-то запомнить: имя игрока, количество кликов или цвет. Для этого мы создаем "переменные" (коробочки с именами). Мы создаем их с помощью слова let.

// Создаем переменную для имени
let myName = "Максим";

// Переменная для очков в игре (числа пишем без кавычек)
let score = 100;

// Если мы хотим вывести это на экран (всплывающее окно), мы используем alert()
alert(myName);
