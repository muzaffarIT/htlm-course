Часть 3: Нажми на меня! 🖱️

Узнаем, как JS может слушать пользователя с помощью событий.

Что такое события (Events)?

Событие — это любое действие пользователя. Например: клик мышкой (click), перемещение мыши, нажатие кнопки на клавиатуре.

Чтобы заставить HTML-элемент (допустим, кнопку) выполнить JS код при клике, мы добавляем ему атрибут onclick.

<!-- HTML код -->
<button onclick="alert('Ауч, ты на меня нажал!')">Кликни!</button>
ДО (Скучная кнопка без onclick)
ПОСЛЕ (Рабочая кнопка)

Попробуй нажать её!

🔥 Мини-задание: Твоя кнопка

Как бы выглядел HTML код кнопки, на которой написано "Выиграть миллион", и при клике на которую появляется всплывающее окошко с текстом: "Шутка!"?

<button onclick="alert('Шутка!')">Выиграть миллион</button>
