Часть 4: Властелин Страницы (DOM) 🧙‍♂️

Учимся менять текст и цвета на лету, не перезагружая сайт!

Что такое DOM?

До этого мы писали alert(...). Но всплывающие окна раздражают! Лучше менять текст прямо на самой странице.

Для этого мы раздаем HTML-элементам уникальные Имена — ID (например id="title"). А затем с помощью JS находим их командой: document.getElementById('title').

// HTML:
// <p id="magic-text">Обычный текст</p>

// Внутри JS скрипта или внутри onclick:
document.getElementById('magic-text').innerHTML = "Теперь я магический!";
document.getElementById('magic-text').style.color = "red";

Как это работает?

  • innerHTML — меняет содержимое (текст) элемента.
  • style.color — меняет CSS цвет этого элемента!

🔥 Мини-задание: Сделай фон синим

У нас есть блок <div id="box"></div>. Какая команда в JS сделает его цвет фона (backgroundColor) синим (blue)?

/* Заметь, в CSS мы пишем background-color, а в JS свойства пишутся слитно с большой буквы: backgroundColor */
document.getElementById('box').style.backgroundColor = "blue";
