Как работает if/else?

Часто в играх или программах нам нужно спросить: ЕСЛИ человек ввел правильный пароль — пусти его, ИНАЧЕ (если неправильный) — покажи ошибку.

Для этого в JavaScript существует конструкция if (если) и else (иначе).

let score = 90;

if (score >= 50) {
    // Этот блок выполнится, если счет больше или равен 50
    alert("Ты выиграл! 🎉");
} else {
    // Этот блок выполнится, если счет меньше 50
    alert("Попробуй еще раз! 💔");
}

Математика в JS

Мы используем значки для сравнения:

  • > — больше
  • < — меньше
  • === — строго равно (да, в JS нужно ставить сразу три "равно"!)
  • !== — не равно

🔥 Мини-задание: Пароль

У тебя есть переменная let password = "123";. Напиши условие if: если password равен "123", сказать alert("Доступ открыт");.

let password = "123";

if (password === "123") {
    alert("Доступ открыт");
}
